# Calisthenics Studio Website (Work in Progress)

![Project Status](https://img.shields.io/badge/Status-In%20Development-orange)

A premium, high-performance website template designed for a Calisthenics and Fitness Studio. Built with a focus on dark-mode aesthetics, smooth animations, and high conversion rates.

> **Note:** This repository is a sanitized template. All personally identifiable information (PII), real-world locations, and private API keys have been redacted.

## 🚀 Features

* **Premium Dark Mode Design**: Uses a sleek `#0e0e0e` background with vibrant kinetic orange (`#f97316`) accents.
* **Responsive Typography**: Massive `10rem` headers on desktop that scale perfectly down to mobile.
* **GSAP Animations**: Silky smooth scroll-triggered animations that bring the page to life without sacrificing performance.
* **No-Friction Forms**: A clean, fully functional membership application form (integrated with EmailJS).
* **Multi-Page Architecture**:
  * `index.html` - High-impact landing page with methodology and class breakdowns.
  * `programs.html` - Detailed age-specific training programs (Toddlers, Kids, Adults).
  * `coaches.html` - Team and founder profiles.
  * `training.html` - Breakdown of group classes vs. personal training.
  * `membership.html` - Lead generation form.
  * `contact.html` - Location and FAQ.

## 🛠️ Tech Stack

* **HTML5** (Semantic structure)
* **TailwindCSS** (via CDN for rapid, scalable styling)
* **GSAP** (GreenSock Animation Platform for scroll interactions)
* **EmailJS** (For form submissions without a backend)
